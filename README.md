# unit-converter

An interactive Python program that converts between common units of length, weight and temperature. Includes unit tests.

## Supported units
- **Length:** mm, cm, m, km, in, ft, yd, mi
- **Weight:** mg, g, kg, lb, oz
- **Temperature:** c, f, k

## Run it
```bash
python converter.py
```
```
Type (length/weight/temperature): length
Value: 5
From unit: km
To unit: mi
5.0 km = 3.107 mi
```

## Run the tests
```bash
python -m unittest
```

## What I practiced
Dictionaries, functions, input validation, exceptions and writing tests with `unittest`.
